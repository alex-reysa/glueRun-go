## Objective

Fifth slice of the stage file's explicitly-OPTIONAL authored-knowledge manifest ingestion for the executable DAG node `rehydrate-path` (stage `S5-routing`, layer `engine_runtime`). The core `requiredCompletion` behavior is already integrated (TASK-0051–0057); this OPTIONAL feature is NOT part of `requiredCompletion` and does not gate the node — completion and gate promotion are operator authority and are not claimed here. TASK-0058–0061 built the full config-gated authored pipeline, whose entry points `singular_ctx_rehydrate_authored_config_render` / `singular_ctx_rehydrate_authored_config_manifest` are integrated but present-but-uncalled.

This slice wires the authored SECTION into the live rehydration-packet injection. Extend TASK-0057's injection path in `engine/l1-drive.sh` (`rehydrate_inject_packet`, ~422, invoked ~508) so that, on a `rehydrate` run, after appending the durable rehydration packet it ALSO appends `singular_ctx_rehydrate_authored_config_render <triggers>` to `$active_prompt` — augmenting the rehydration packet with the eligible authored-knowledge entries. The config gate (TASK-0061) internally checks `SINGULAR_CTX_MANIFEST` (default 0) and the optional `singular.config.json` `contextManifest` field, so with either OFF it returns empty and nothing is appended. The authored manifest-into-strategy-event recording (merging `singular_ctx_rehydrate_authored_config_manifest` entries into TASK-0055 / TASK-0056's recorded manifest) is the FINAL separate slice and is OUT OF SCOPE here.

Scope, node `rehydrate-path`, layer `engine_runtime`:

- Append the authored block AFTER the durable packet, under a brief reference-only / not-authoritative wrapper; the per-entry authored-knowledge framing already comes from TASK-0060's render.
- Authored ingestion fires only on `rehydrate` runs (`worker_strategy` == `rehydrate`), augmenting the rehydration packet — matching the stage file's optional-slice scope. The broader all-prompt A/B injection is a separate measurement track (integration point 4) and is not this slice.
- The hook stays a minimal delegating append into `singular_ctx_rehydrate_authored_config_render`; no config/selection/render logic is inlined into the driver.
