## Objective

Advance the `experiment-run` executable DAG node (layer `evaluation`) by shipping the deterministic, strictly read-only tooling that computes the RAW METRICS the operator's `experiment-report.md` references at merge: escape rate per arm, cost per arm, and the bias directional-disagreement rate. This task is the measurement code + tests ONLY. Running the paired-audited A/B experiment, authoring `experiment-report.md`, and recording per-knob default decisions in `docs/orchestration/decisions.md` remain OPERATOR authority (kind: evaluation) and are out of scope here; this task neither declares nor gates node completion.

All logic lands in one new `engine/ctx-experiment-report.sh`, auto-sourced by the ctx-loader block and defining new functions only. No existing engine path invokes them, so the engine is byte-identical with the file present (OFF-parity intrinsic, mirroring the `ctx-metrics.sh` idiom). Every function reads only an events log (`events.ndjson`, whose relevant records are `ctx.arm_assigned` carrying taskId and arm, `ctx.paired_audit` carrying the verdict/findings disagreement flag, and `ctx.critic_recheck` carrying the per-finding addressed|survives|obsolete dispositions) plus the existing per-task metrics; it creates, moves, or mutates nothing (no run artifact, index, event, lease, or task file).

Implement three chained slices in order, all inside `engine/ctx-experiment-report.sh`:

1. Per-arm escape-rate aggregator: group accepted tasks by their `ctx.arm_assigned` arm (A = control / M0 knob-state, B = treatment) and compute each arm's escape rate as the fraction of accepted tasks with a flagged escape signal (a `ctx.paired_audit` disagreement, i.e. paired verdict not accepted OR non-empty paired findings). Missing or empty inputs yield a well-formed zeroed result (fail-safe), never an error.

2. Bias directional-disagreement-rate aggregator: over the set a fresh paired audit flagged, compute the rate at which the context-aware reviewer (`ctx.critic_recheck`) nonetheless dispositioned the finding addressed/obsolete rather than survives. That directional disagreement between the tainted context-aware reviewer and the independent fresh auditor IS the bias estimate. The aggregator only MEASURES this divergence; it never lets the context-aware approval override or suppress a fresh paired-audit flag (evidence invariance; advocate/skeptic line preserved).

3. Composed merged raw-metrics artifact: emit one deterministic JSON object on stdout (keys sorted, stable for a given input set) conforming to the new additive schema `gluerun.orchestration.ctx-experiment-report.v0`, merging both arms' escape rates, a per-arm cost rollup (tokens + wall-clock per accepted task, grouped by arm over the existing per-task metrics), and the bias directional-disagreement rate. This object is the raw metrics artifact the operator's `experiment-report.md` references.

## Context packet

### Decisions

- Package escape-rate, cost, and bias as ONE read-only aggregator file with a new additive schema, mirroring the `ctx-metrics.sh` idiom (stdout JSON, sorted keys, zeroed fail-safe on empty input) and the TASK-0070 emitted-conformance guard, because the exit gate demands referenceable raw metrics artifacts and a schema-anchored artifact is the loss-free way to reference them.

### Rejected alternatives

- Extending `engine/ctx-metrics.sh` in place — rejected: it is a pre-existing file; the new-file convention keeps this additive and present-but-uncalled (OFF-parity intrinsic).
- Emitting `experiment-report.md` or flipping knob defaults here — rejected: those are operator-driven (kind: evaluation) and are the node/area completion authority, not a strict-test-first worker's.

### Assumptions

- [validated] The events log already carries `ctx.arm_assigned` (taskId, arm), `ctx.paired_audit` (disagreement = verdict not accepted OR non-empty findings), and `ctx.critic_recheck` (per-finding addressed|survives|obsolete) — basis: engine/ctx-ab.sh, engine/ctx-paired-audit.sh, engine/ctx-critic-recheck-classify.sh.
- [open] Integration-failure/revert escape signals beyond paired-audit disagreement may be absent from a given fixture; the aggregator must treat their absence as zero, not error — basis: the fail-safe contract of ctx-metrics.sh.
