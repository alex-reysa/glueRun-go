## Objective

Close the executable DAG node `subgraph-rehydrate` (stage `S6-graph`, layer
`engine_runtime`) toward its requiredCompletion with the composed end-to-end
guard it still lacks. The whole runtime path is integrated and wired — selector
(TASK-0099), source resolver (TASK-0101), order-preserving assembler
(TASK-0102), A/B arm decider (TASK-0104), ctx-route.sh decision wire-in
(TASK-0105), and the l1-drive.sh inject + ctx-rehydrate-event.sh record wire-in
(TASK-0106) — but each is covered ONLY by its own per-slice test
(test-ctx-rehydrate-subgraph-{arm,inject,packet,route,sources}.sh and
test-ctx-rehydrate-subgraph.sh). No single test exercises the whole
requiredCompletion in ONE fixture-lineage walk, which is exactly the stage exit
gate (fixture lineage produces the documented selection).

Add `tests/test-ctx-rehydrate-subgraph-e2e.sh`: author one deep-lineage fixture
graph corpus (canonical `nodes.jsonl` + `edges.jsonl` per
`schemas/context-graph.v0.schema.json`) plus durable fixture artifacts on disk
at each node `provenance.sourcePath`, then drive the integrated composed path —
`gluerun_ctx_rehydrate_subgraph_assemble` and the WIRED selectors
`gluerun_ctx_route_subgraph_render` / `gluerun_ctx_route_subgraph_manifest` — and
assert the documented selection, in one walk:

- Deep lineage is walked: the task plan-version, a surviving critique finding,
  and an open assumption appear in the selection.
- Rejected observations excluded: a finding reached ONLY across a
  `rejects_observation` edge appears in NEITHER the packet NOR the manifest.
- Contradictions surfaced first: the node flagged by an open
  `contradicts`/`invalidates` edge with no `supersedes` resolution is the FIRST
  packet section.
- Caps unchanged: section bodies are capped at GLUERUN_CONTEXT_SECTION_MAX_CHARS
  and shrinking the knob shrinks a section deterministically.
- Manifests unchanged: the manifest conforms to
  gluerun.orchestration.ctx-rehydrate-manifest.v0 and its source ids + sha256s
  EXACTLY match the packet's included sources (the same-sources invariant).
- Determinism: the packet and manifest are byte-identical across repeated runs.
- OFF-parity: with GLUERUN_CTX_SUBGRAPH_REHYDRATE unset/0 the wired selectors
  yield flat/empty and the route/inject/record path is byte-identical to the flat
  capsule behavior.
- Taint-unreachability / evidence invariance: the subgraph rehydrate path confers
  NO independence and the rehydrate strategy stays tainted per
  `gluerun_ctx_route_strategy_tainted`; nothing is recorded as authoritative.

This is a strict-test-first GUARD over the composed integrated path: it changes
NO engine/ code; it is red before authoring (and would catch any composed-path
gap — e.g. contradictions-first order or caps not surviving the full route
render) and green after. Reuse the fixture-corpus authoring convention the
integrated graph-query and selector tests already use, with only existing
context-graph.v0 node/edge types.

## Acceptance Criteria

- Over one deep-lineage fixture corpus (task -> attempt -> plan-version ->
  critique -> finding, plus an assumption, a capsule, a decision, a rejected
  observation, and an open contradiction) with durable fixture artifacts at each
  node provenance.sourcePath, the composed assemble/render path emits a packet
  whose sections are contradictions-first and EXCLUDE the rejected observation,
  and a manifest whose sources exactly match the packet's included sources.
- Section bodies honour GLUERUN_CONTEXT_SECTION_MAX_CHARS (caps unchanged) and
  the manifest conforms to gluerun.orchestration.ctx-rehydrate-manifest.v0
  (manifests unchanged); both are byte-identical across repeated runs.
- With GLUERUN_CTX_SUBGRAPH_REHYDRATE unset/0, the wired selectors yield
  flat/empty and the whole path is byte-identical to the flat capsule behavior
  (OFF-parity).
- The subgraph rehydrate path confers no independence and the rehydrate strategy
  stays tainted (`gluerun_ctx_route_strategy_tainted`); no source is recorded as
  authoritative (taint-unreachability / evidence invariance).
- The guard modifies no engine/ file; `tests/test-engine-clean.sh` stays green.
- Gate candidate: `tests/test-ctx-rehydrate-subgraph-e2e.sh` is red before
  authoring (or on any composed-path gap) and green after; it is proposed as the
  subgraph-rehydrate exit-gate evidence but does NOT itself declare the node
  complete.

## Context packet

Decisions:
- A new composed guard test that owns no engine code — why: the runtime path is
  already integrated per-slice; the missing coverage is the single-walk
  requiredCompletion proof (the analogue of TASK-0069 for rehydrate-path and
  TASK-0090 for graph-projector); a new test keeps the scoped gate.
- Drive the WIRED selectors (`gluerun_ctx_route_subgraph_render` /
  `gluerun_ctx_route_subgraph_manifest`) plus the assembler rather than sourcing
  the whole l1-drive.sh script — why: the composed selection path is exercisable
  through the integrated selector/pure functions; the injected-packet driver
  behavior is already covered by TASK-0106, so re-driving the script is brittle
  and redundant (mirrors how TASK-0069 composed the pure bricks).

Assumptions:
- [validated] the full subgraph runtime path is integrated and wired — basis: the
  existing-tasks ledger (TASK-0102/0104/0105/0106) and engine/ctx-route-subgraph.sh.
- [validated] no existing test exercises the whole requiredCompletion in one
  lineage walk; the per-slice tests each cover one brick — basis: the tests/
  listing.
- [open] the same-sources invariant (packet sources == manifest sources by
  construction) holds through the composed route-render path — basis: TASK-0106
  wired both sites to one selector; the guard must ASSERT it end-to-end, not
  assume it.

  guard asserts only the behavior this composed path ships.
- Sourcing and driving the whole l1-drive.sh script for injection — why-not:
  brittle, and the injected-packet behavior is already covered by TASK-0106; the
  composed selection proof is achievable through the integrated
  selector/assembler functions.

  authority the guard asserts remains true for the subgraph rehydrate path
