## Objective

Advance the executable DAG node `subgraph-rehydrate` (stage `S6-graph`, layer
`engine_runtime`) by closing the injection/recording gap left after TASK-0105.
The route now DECIDES `rehydrate` over the subgraph manifest on the treatment
arm, but the packet the model actually receives and the manifest the strategy
event records are still FLAT: `rehydrate_inject_packet` in `engine/l1-drive.sh`
injects the flat packet (`gluerun_ctx_rehydrate_sources` ->
`gluerun_ctx_rehydrate_packet`), and `gluerun_ctx_rehydrate_event_data` in
`engine/ctx-rehydrate-event.sh` records the flat manifest. So on the treatment
arm the implementer gets flat capsule context and the event mis-records the
sources — breaking the documented invariant that the injected packet and the
recorded manifest carry the SAME sources by construction.

Close it atomically with three ordered slices:

1. New shared selector in `engine/ctx-route-subgraph.sh`:
   `gluerun_ctx_route_subgraph_render <task_id> <packet|manifest>`. When
   `gluerun_ctx_rehydrate_subgraph_arm_mode <task_id> <graphDir>` == subgraph
   (graphDir = ${GLUERUN_CTX_GRAPH_DIR:-.gluerun-state/graph}), resolve
   node = `gluerun_graph_node_id`(`gluerun_graph_identity task <task_id>`) and
   print `gluerun_ctx_rehydrate_subgraph_assemble <graphDir> <node> <mode>`,
   returning 0. Otherwise print nothing and return non-zero, signalling the
   caller to keep its existing FLAT composition. Both call sites key on the SAME
   task_id, arm-mode, and node, so the injected packet and the recorded manifest
   carry the SAME subgraph sources by construction.

2. Minimal hook in `engine/l1-drive.sh` `rehydrate_inject_packet`: before the
   flat composition, try `gluerun_ctx_route_subgraph_render "$task_id" packet`;
   if it yields a non-empty packet, inject THAT under the same reference-only /
   NOT-authoritative header and skip the flat durable composition; otherwise
   leave the existing flat path — including `decision_source_extra` and the
   authored-knowledge append — byte-identical.

3. Minimal hook in `engine/ctx-rehydrate-event.sh` `gluerun_ctx_rehydrate_event_data`:
   before the flat manifest composition, try
   `gluerun_ctx_route_subgraph_render "$task_id" manifest`; if it yields a
   non-empty manifest, record THAT as the strategy-event manifest; otherwise
   leave the existing flat manifest (including extras) byte-identical.

Feature-flag discipline: GLUERUN_CTX_SUBGRAPH_REHYDRATE defaults 0, so
`gluerun_ctx_route_subgraph_render` always returns non-zero/empty and both sites
use the flat path — byte-identical to today. The subgraph branch is reachable
only with the knob on, the treatment arm, and a present non-empty graph corpus
(all re-checked by the integrated arm decider). GLUERUN_REHYDRATE still gates
whether any rehydration happens at all.

Evidence invariance / advocate-skeptic line: the injected subgraph packet stays
under the reference-only / NOT-authoritative header; the rehydrate strategy stays
tainted per `gluerun_ctx_route_strategy_tainted`; the recorded manifest documents
exactly the injected sources (same-sources invariant preserved); nothing is
marked authoritative and no independence is conferred.

  and recording never disagree on the subgraph sources.
- The injected subgraph context stays under the reference-only / NOT-authoritative
  header; the rehydrate strategy stays tainted; no writes beyond the prompt

- Gate candidate: `tests/test-ctx-rehydrate-subgraph-inject.sh` is red before the

## Context packet

Decisions:
- A single shared selector `gluerun_ctx_route_subgraph_render` feeds BOTH the
  injection and the recording sites — why: the documented invariant (injected
  packet and recorded manifest are the same sources by construction) requires
  both to follow the SAME arm-mode decision and the SAME node; one helper
  guarantees it and keeps each driver hook minimal (planner-contract rule 2).
- A subgraph-first guard that FALLS THROUGH to the untouched flat code on
  non-zero — why: preserves flat byte-identity (including decision_source_extra
  and authored knowledge) without refactoring the flat path, so OFF-parity is
  trivially exact.
- Injection and recording land in ONE task — why: splitting them would
  transiently break the injected/recorded same-sources invariant (inject
  subgraph, record flat), an evidence-integrity regression an auditor would
  reject; they must be atomic.

Assumptions:
- [validated] `rehydrate_inject_packet` (engine/l1-drive.sh) composes the FLAT
  packet and fires when worker_strategy==rehydrate, which the route now emits on
  the treatment arm; `task_id` is in scope — basis: engine/l1-drive.sh.
- [validated] `gluerun_ctx_rehydrate_event_data` (engine/ctx-rehydrate-event.sh)
  records the FLAT manifest and its header states the recorded manifest must
  match the injected packet's sources; `task_id` is arg 2 — basis:
  engine/ctx-rehydrate-event.sh.
- [validated] the arm decider, the subgraph assembler, and the identity
  primitives are integrated and deterministic — basis: TASK-0104, TASK-0102,
  TASK-0076.
- [open] the subgraph packet does NOT need the flat `decision_source_extra` —
  basis: the subgraph selector maps decision nodes to decision-record specs, so
  the graph supplies decisions; the extra is a flat-only mechanism the worker
  must not graft onto the subgraph branch.

Rejected alternatives:
- Doing the injection wire-in alone and deferring manifest recording — why-not:
  transiently breaks the injected/recorded same-sources invariant (integrity
  regression).
- Refactoring the flat composition out of both drivers into the helper —
  why-not: risks changing flat bytes (extras / authored ordering); a
  fall-through guard preserves the flat path exactly with a smaller diff.
- Extending `gluerun_ctx_route_subgraph_manifest` (TASK-0105) to also emit
  packets and forward extras — why-not: it is the route-DECISION selector keyed
  on (meta,key) without extras; overloading it would change its integrated route
  call site.

Inspected symbols:
- `rehydrate_inject_packet` (engine/l1-drive.sh) — role: the flat packet
  injection site that gets the subgraph-first guard; its authored-knowledge
  append is independent and stays.
- `gluerun_ctx_rehydrate_event_data` (engine/ctx-rehydrate-event.sh) — role: the
  strategy-event manifest recorder that must match the injected packet; gets the
  parallel guard.
- `gluerun_ctx_route_subgraph_manifest` (engine/ctx-route-subgraph.sh) — role:
  TASK-0105 route-DECISION selector keyed on (meta,key) without extras; NOT
  reused at the recording site — the new render helper is separate so the flat
  recording path keeps its exact extras contract.
