## Objective

Add the composed end-to-end guard that pins the CORE `requiredCompletion` of the executable DAG node `rehydrate-path` (stage `S5-routing`, layer `engine_runtime`) as a SINGLE deterministic walk over the fully-integrated stack (TASK-0051-0068). An integrated-frontier re-read confirms every behavioral predicate is built: the assembler ranks exactly seven durable source classes (`engine/ctx-rehydrate.sh` RANK 0-6 — task-packet, implementer-capsule, reviewer-capsule, findings-ledger, assumptions-ledger, critique-record, decision-record) and all seven are now resolved into both the injected packet and the recorded manifest (ranks 0-5 via the run_dir resolver, rank 6 via TASK-0068's decision-source leaf + l1-drive wire-in); determinism, the per-section cap, quarantine exclusion, OFF-parity, and rehydrate-tainted independence-unreachability are each covered by per-slice tests. What no existing test does is assert these TOGETHER, through the real driver, on one refused-resume run — so a future engine change could silently regress the COMPOSED node (e.g. drop a source class from the packet while the per-slice test still passes) with no guard catching it.

This task owns exactly one new test file `tests/test-ctx-rehydrate-e2e.sh` that drives the existing engine functions in a harness (following the established `tests/test-ctx-rehydrate-inject-drive.sh` / `tests/test-ctx-rehydrate-event-drive.sh` pattern) WITHOUT modifying any engine file, and asserts the composed contract in one walk. It closes the test-coverage dimension of the `requiredCompletion` (whose final clause is a passing test) by proving the whole predicate end-to-end; it does not add new product behavior and it does not declare the node complete — completion and gate promotion are operator authority.

- `tests/test-ctx-rehydrate-e2e.sh` is written FIRST and is a genuine guard: it MUST fail (red) if any composed assertion below is unmet (the test includes at least one assertion that fails when a durable source class is dropped from the packet or manifest, proving it is not a tautology), and it passes (green) against the integrated stack; `bash tests/test-ctx-rehydrate-e2e.sh && bash tests/test-engine-clean.sh` is green.
- All-classes packet: on a refused-resume lineage step with `SINGULAR_CTX_ROUTING=1` and `SINGULAR_REHYDRATE=1` and a fixture `run_dir` populated with every durable source class (task packet, implementer/reviewer capsules, findings + assumption ledgers, critique record) plus a fixture repo decision log, the routing spine yields `rehydrate` and the injected `$active_prompt` durable-context section contains every present durable class in the assembler's fixed rank order, each body truncated to at most `SINGULAR_CONTEXT_SECTION_MAX_CHARS`.
- Manifest completeness + consistency: the `context.strategy_selected` event data `manifest.sources` lists exactly the same class ids that were injected, each with its sha256; the injected packet and the recorded manifest describe the identical source set (injected<->recorded consistency).
- Quarantine exclusion: a durable class whose source has a `.quarantined` sibling (or is itself a `*.quarantined` path) is absent from BOTH the injected packet and the recorded manifest, exercising the single `singular_ctx_artifact_exclude` quarantine authority through the composed path.
- Determinism: two rehydrate runs over identical fixture bytes yield byte-identical injected packet and byte-identical event data.
- OFF-parity: with `SINGULAR_REHYDRATE` unset, no `rehydrate` strategy is emitted, no durable-context section is injected into `$active_prompt`, and the recorded strategy is `fresh` — byte-identical to the legacy path.
- Taint independence (asserted in the same walk): `singular_ctx_route_independence_admit rehydrate` at the independence-pinned steps (final-audit, paired-audit) returns `refuse tainted`, so a rehydrated (tainted) session is provably never eligible for an independence-required step, under any knob values.
- Gate candidate: this composed guard demonstrates the `rehydrate-path` `requiredCompletion` end-to-end over the integrated stack — all durable source classes reach the packet and the manifest, deterministic, capped, quarantine-aware, OFF-parity byte-identical, and rehydrate-tainted-unreachable for independence steps. Proposed as the node's gate candidate; this task does not declare the node or area complete.
