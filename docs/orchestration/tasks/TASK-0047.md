## Objective

Complete the `routing-module` executable DAG node (layer `engine_runtime`) by shipping its composed orchestrator spine — `engine/ctx-route.sh` — now that every leaf it depends on is integrated: the window-pressure and diff-volume gates (TASK-0045), the generalized session lease and the taint / independence pin (TASK-0046), and the two resume deciders it wraps, `gluerun_session_resume_decide` (task role, `engine/lib.sh`) and `gluerun_planner_resume_decide` (planner role, `engine/ctx-planner-resume.sh`). This is the leaf-before-orchestrator composition step this node deferred to last, exactly as `engine/ctx-plan-revise-loop.sh` (TASK-0023) composed its leaves.

`gluerun_ctx_route <role> <ctx…>` returns EXACTLY one line — one of `continue|resume|fork|fresh|rehydrate <arg-or-reason>` — with every decision carrying its reason. The full routing capability is behind `GLUERUN_CTX_ROUTING` (default 0); OFF is byte-identical to the legacy decide paths. Routing is composed boolean gates plus the wrapped model-decider, never a numeric score. `engine/ctx-route.sh` is a new auto-sourced file that wraps (does not rewrite) the two deciders; no existing engine path invokes it, so with the flag OFF and the file present-but-uncalled the engine is byte-identical — the `l1-drive.sh` second-wave hook and the `ctx-metrics.sh` strategy/outcome split are later slices and are OUT OF SCOPE here.

Composition when `GLUERUN_CTX_ROUTING=1`:
- Independence pin first: for an independence-required step (`final-audit`, `paired-audit`, via `gluerun_ctx_route_independence_admit`) the router is PINNED to `fresh` and never emits `resume`/`rehydrate` — structurally, with no knob able to reroute it.
- Otherwise it delegates the baseline resume/fresh decision to the role's wrapped decider and, on a would-be `resume`, applies the additional fail-closed resume gates (first refusal wins), each downgrading to `fresh <reason>`: a live generalized session lease (`gluerun_ctx_route_session_lease_live`), window pressure (`gluerun_ctx_route_window_gate`), diff volume (`gluerun_ctx_route_diff_gate`).
- `fork` is a reserved strategy (alphabet + event slot; may be unused this stage).

## Acceptance Criteria

- `engine/ctx-route.sh` defines `gluerun_ctx_route` and prints EXACTLY one line `<strategy> <arg-or-reason>` where `<strategy>` is one of `continue`, `resume`, `fork`, `fresh`, `rehydrate`; it never exits non-zero, and every emitted decision carries a reason (or, for `resume`, the session id) enumerated by the test.
- OFF-parity: with `GLUERUN_CTX_ROUTING` unset or not equal to 1 (default 0), for a given role fixture `gluerun_ctx_route` emits byte-for-byte exactly what the role's wrapped decider emits — `resume <id>` or `fresh <reason>` from `gluerun_session_resume_decide` (task role) / `gluerun_planner_resume_decide` (planner role) — with no new gate applied and no strategy outside {`resume`,`fresh`} appearing.
- With `GLUERUN_CTX_ROUTING=1` and a fixture where the wrapped decider would `resume`: a window-pressure refusal downgrades the decision to `fresh window-pressure`; independently, a diff-volume refusal downgrades it to `fresh diff-volume`; independently, a live generalized session lease for the role's session downgrades it to `fresh` with the lease reason. Each gate reason is enumerated by the test.
- Taint / independence pin: with `GLUERUN_CTX_ROUTING=1`, for step `final-audit` and step `paired-audit` the router emits `fresh <reason>` and NEVER `resume` or `rehydrate`, even when the wrapped decider would `resume` and even with routing knobs set to arbitrary values — proving independence-pinned steps are structurally unreachable by resumed/rehydrated sessions (composed via `gluerun_ctx_route_independence_admit`).
- The router wraps, and does not reimplement, `gluerun_session_resume_decide` and `gluerun_planner_resume_decide`: the baseline resume/fresh gates come from those functions; the router adds only the lease/window/diff gates and the strategy/taint framing on top. Routing is composed boolean gates plus the wrapped decider (fail-closed, first refusal wins), never a numeric score; `fork` is reserved in the alphabet and may be unused this stage.
- `tests/test-ctx-route.sh` exercises a per-role strategy table (task-role and planner-role fixtures), both new gates, the taint exclusion at the independence-required steps, and OFF-parity; it is red before implementation and green after; `bash tests/test-engine-clean.sh` stays green (no project-specific symbols in `engine/`).
- GATE CANDIDATE (node-level, not declared here): with this spine integrated, `routing-module` returns the five reason-coded strategies behind `GLUERUN_CTX_ROUTING` (default 0), enforces the window-pressure and diff-volume gates and the generalized session lease, and makes independence-pinned steps unreachable by resumed/rehydrated sessions — the node's full `requiredCompletion`, with `test-ctx-route.sh` green.
