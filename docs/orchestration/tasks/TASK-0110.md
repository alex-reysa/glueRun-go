## Objective

Two hygiene defects in the worker try loop of `engine/l1-drive.sh` `run_worker_phase`:

1. Stale `last-message.json` masks failures. Every try passes
   `--output-last-message "$run_dir/last-message.json"`, and the file is never removed between
   tries. If try 1 dies before writing output, failure classification is handed try 0's stale
   file, which can suppress an `empty-output` classification. The auditor loop already does
   this correctly — it runs `rm -f "$audit_record"` at the top of every try. Mirror that:
   remove `last-message.json` (and any per-try equivalent) at the top of each worker try
   before the runner spawns.

2. The try>0-fresh invariant is enforced by code but asserted by no test. The gate
   `[[ "$worker_try" -eq 0 && -n "$worker_resume_id" ... ]]` (and the auditor twin at
   `audit_try -eq 0`) is the only thing keeping an infra retry from resuming an advocate
   session out-of-contract. `tests/test-session-affinity.sh` asserts attempt-1-fresh and
   attempt-2-resume at the decision boundary, but nothing drives an infra retry and asserts
   the second try's argv omits `--resume-session`. Add that regression test for both roles.
   TASK-0124 will later relax this gate deliberately; this test is the contract it must
   renegotiate rather than silently break.

3. The rel-01 archive fixture's literal whole-tree equality is not concurrency-safe. During
   `RUN-20260814T010432Z-76912`, both host gates failed only because the concurrently running
   TASK-0115 appended its own legitimate run evidence beneath the shared `.singular-state`.
   Replace the recursive equality checks over the complete live checkout, shared state root,
   and authoritative event bytes with a causal leakage proof that remains strict at
   `maxConcurrent=3`:

   - capture the literal caller checkout/state/event paths before any fixture rebinding;
   - seed private fixture-local source-time decoy state, event, and config paths with canaries;
     these decoys are distinct from both active iteration event logs, and their complete
     inventories must remain byte-identical after each archive call and final drain;
   - generate one unguessable nonce, include it in each distinct fixture run ID and marker, run
     the real archive helper twice in one shell process, and require its event emission exactly
     once in each active fixture event log with no cross-iteration event;
   - require the nonce to remain absent from the literal authoritative event file and from every
     nonce-named path under the literal caller-state namespace;
   - fingerprint fixed literal caller-checkout protected files (`.gitignore`, `engine/lib.sh`,
     `engine/l1-drive.sh`, and `tests/test-per-try-artifacts.sh`) by type, mode, and content before
     and after each call and the bounded final drain; and
   - do not compare the complete live checkout, shared state tree, or authoritative event bytes:
     unrelated sibling lifecycle writes are valid and must not make the focused test red.

   Preserve the existing archive-copy assertions, two same-process executions, distinct roots,
   fixture-event isolation, and bounded late-writer drain.

Recovery seed (mandatory prompt input): no accepted commit exists for
