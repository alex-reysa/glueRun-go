## Objective

Advance the `routing-module` executable DAG node (layer `engine_runtime`) to its LIVE behavior by wiring the integrated `gluerun_ctx_route` strategy dispatcher (TASK-0047 — composing the window-pressure and diff-volume gates, the generalized session lease, and the taint independence pin) into the running driver `engine/l1-drive.sh` behind `GLUERUN_CTX_ROUTING` (default 0). Today `gluerun_ctx_route` is present-but-uncalled, so the flag gates nothing in the running engine and the taint independence guarantee holds only in the library. This is the sanctioned second-wave `l1-drive.sh` hook this node owns (stage-5: the routing hook chains behind the paired-audit hook).

The driver makes two live session-resume decisions through `gluerun_session_resume_decide` — the implementer session (`engine/l1-drive.sh:436`) and the reviewer/auditor session (`engine/l1-drive.sh:675`), each parsed into a `<strategy> <reason>` string that feeds a `context.strategy_selected` event. This task routes both through the integrated dispatcher, keeping each call-site minimal by delegating into a new ctx-* adapter (planner-contract rule 2).

The wire-in:
- New `engine/ctx-route-drive.sh` defines `gluerun_ctx_route_decide <role> <step> <ctx…>` — a thin adapter that assembles the per-role routing context (step key, session transcript path, session-lease key) and returns the decision by delegating to `gluerun_ctx_route`. It adds NO new decision logic: the OFF/ON gating and the wrapped legacy decider already live inside `gluerun_ctx_route`.
- Minimal call-site edits in `engine/l1-drive.sh` at the implementer and reviewer decision sites replace the direct `gluerun_session_resume_decide` call with a `gluerun_ctx_route_decide` delegation, preserving the exact downstream `<strategy> <reason>` parsing and `context.strategy_selected` events.
- OFF (`GLUERUN_CTX_ROUTING` unset or not equal to 1, default 0): the decision string, the resume/fresh worker and auditor invocations, and every emitted event are byte-identical to today.
