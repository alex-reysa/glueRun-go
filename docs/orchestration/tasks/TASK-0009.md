## Objective

Implement the planner-role resume decision for executable DAG node `planner-resume-gates` (stage `S1-planner-persistence`, area `session`, layer `engine_runtime`) as a new, present-but-uncalled library brick `engine/ctx-planner-resume.sh` that defines `gluerun_planner_resume_decide`. It is the planner-role variant of the already-integrated task-role decider `gluerun_session_resume_decide` in `engine/lib.sh`: the same single-line `resume <sessionId>` / `fresh <reason>` contract, ordered fail-closed gates where the first failing gate names the reason, reusing the `gluerun.orchestration.session-meta.v0` shape. The new file defines functions only; NO existing engine path invokes it, so with the file present-but-uncalled the engine is byte-identical to current behavior (mirroring the integrated `engine/ctx-planner-session.sh`).

This slice is the decider core plus its gate-reason test. The sanctioned follow-up slices of this node are OUT OF SCOPE here and are NOT owned by this task: the `engine/generate-tasks.sh` call site that consults the decider only when `GLUERUN_PLANNER_SESSION=1`, the resume-refused rc-86 in-run fresh fallback (mirroring the worker path in `l1-drive.sh`), the `context.strategy_selected` events carrying `role: planner` plus the gate reason so `ctx-metrics.sh` sees planner routing, and the finalize-side alignment that stores the TEMPLATE sha in `promptSha256` with a finalize->decide round-trip proof. Splitting them out preserves driver-hook scarcity and the single-new-`engine/ctx-*.sh`-per-slice convention.

Gate deltas from the task-role decider, per the stage file section for `planner-resume-gates`:

- Enable gate: when `GLUERUN_PLANNER_SESSION` is unset or not `1`, return `fresh disabled` (default 0 = OFF).
- REPLACE the runId/task-equality gate (task-role gate 5) with a node-lineage gate: `meta.node` must equal the target node (else `fresh node-mismatch`), and `meta.headShaAtCreate` must be an ancestor of the current target-branch head via `git merge-base --is-ancestor` (else `fresh head-rewritten`).
- KEEP the planner-role gate (advocate/skeptic line): resume only a meta whose `role` is exactly `planner`; any other role returns `fresh role-mismatch`.
- KEEP a prompt-template gate keyed on the TEMPLATE sha: compare `meta.promptSha256` against sha256 of the planner template file `docs/orchestration/prompts/l1-planner.md` (NOT the rendered prompt, which varies per frontier by design); mismatch returns `fresh prompt-template-changed`.
- ADD a session-lease gate: a live lease held at the canonical path `.gluerun-state/sessions/planner/<node>.lease` returns `fresh leased` (parallel L1 fanout must never resume one planner session concurrently).
- KEEP the remaining task-role gates and reasons: missing/unparseable meta -> `fresh no-session`; empty provider or sessionId -> `fresh no-session-id`; runner changed -> `fresh runner-changed`; expired per `GLUERUN_SESSION_MAX_AGE_SEC` -> `fresh expired`; cwd moved -> `fresh worktree-moved`.
- When every gate passes, print `resume <sessionId>`.

All gates fail closed: any ambiguity (missing/unparseable meta, unreadable template, indeterminate ancestry, non-numeric/absent fields) resolves to `fresh <reason>`, never `resume` (evidence invariance — routing never makes a fresh-required decision resumable by weakening a gate).
