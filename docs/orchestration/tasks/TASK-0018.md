## Objective

Complete the executable DAG node `critique-import-gate` (stage `S2-plan-critique`, area `plancritic`, layer `engine_runtime`, kind runtime) by landing its final wiring: the small `reconcile.sh` / L0 import call-site hook that routes the L1 fanout import through the integrated critique-aware orchestrator behind `GLUERUN_PLAN_CRITIQUE`, so L0 import honors the plan critic verdict. This is the sanctioned driver-file hook this node owns; every piece it composes is already integrated — the pure decider `gluerun_ctx_critique_import_decide` (TASK-0015), the reject disposition `gluerun_ctx_critique_import_gate` (TASK-0016), and the drop-in critique-aware fanout `gluerun_ctx_critique_import_fanout` (TASK-0017), which mirrors `gluerun_l1_fanout` exactly and prints the same `l1_planner_failures=` / `l1_import_rejections=` summary lines the caller parses.

The hook is minimal and lives only in the L1 parallel branch of `engine/reconcile.sh` (the `GLUERUN_ENABLE_L1_PARALLEL=1` case that today runs `l1_out=$(gluerun_l1_fanout "$run_id" "$base_sha")`). When `GLUERUN_PLAN_CRITIQUE=1` the branch instead calls `gluerun_ctx_critique_import_fanout "$run_id" "$base_sha"`, feeding its identical summary output into the same `l1_out` parsing; when `GLUERUN_PLAN_CRITIQUE` is `0` or unset it calls `gluerun_l1_fanout "$run_id" "$base_sha"` exactly as today, so the default path is byte-identical to current behavior (feature-flag discipline: default-OFF and byte-identical when OFF). No orchestration logic is added to `reconcile.sh` — the hook is a knob-gated if/else delegating into the integrated orchestrator — and `engine/lib.sh` is not modified. The single-node (non-parallel) `generate-tasks.sh` branch is left untouched.

With the knob ON, the effect is the node required completion: staged batches the plan critic marks `revise` or `park` (or whose critique record is missing / unreadable / schema-invalid) are NOT imported — the orchestrator withholds them, records `origin.l1_import_rejected` reason `plan-critique`, and fails the node lease as planning-failed so the frontier is re-planned — while `approve` batches import through the reused `gluerun_l1_import_staged`.

This slice also updates the frozen present-but-uncalled assertion in `tests/test-ctx-critique-import-fanout.sh`: that test currently asserts no engine path references `gluerun_ctx_critique_import_fanout` and that `reconcile.sh` still calls `gluerun_l1_fanout`. Now that `reconcile.sh` legitimately invokes the orchestrator behind the knob, the assertion is flipped to require exactly that wiring (orchestrator invoked under `GLUERUN_PLAN_CRITIQUE`, with `gluerun_l1_fanout` retained for the OFF path), plus coverage that the L1 branch routes to the orchestrator when ON and to plain fanout when OFF. The decider test `tests/test-ctx-critique-import.sh` stays green unmodified: the hook references `gluerun_ctx_critique_import_fanout`, not the `gluerun_ctx_critique_import_decide` / `gluerun_ctx_critique_import_record_path` symbols that test greps for. Advocate/skeptic line and evidence invariance hold: enforcement is layered over the read-only, default-runner skeptic critique, the hook never weakens, resumes into, or bypasses the un-bypassable implementation auditor, and the ON path only ever withholds import — it never fabricates an approval.
