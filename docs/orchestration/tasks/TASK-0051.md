## Objective

First strict-test-first slice of the executable DAG node `rehydrate-path` (stage `S5-routing`, layer `engine_runtime`). Introduce a new pure, read-only `engine/ctx-rehydrate.sh` that assembles a deterministic, section-capped, quarantine-aware rehydration packet from durable artifacts only, plus the packet manifest (which artifacts, which content hashes) that a later routing slice will record in the strategy event.

The `rehydrate` strategy already exists as a reserved alphabet slot in the integrated `engine/ctx-route.sh` (routing-module node), but nothing assembles the injected context yet. This slice builds that assembler as the smallest brick under the node's requiredCompletion ("Deterministic capped rehydration packets from durable artifacts (quarantine-aware) …"). The routing wire-in (routing `rehydrate` instead of bare `fresh` on a refused resume behind `GLUERUN_REHYDRATE=1`, recording the manifest into the strategy event) and the `l1-drive.sh` injection hook are SEPARATE later slices and are OUT OF SCOPE here.

Behavior of `engine/ctx-rehydrate.sh` (layer engine_runtime, node `rehydrate-path`):

- A function (e.g. `gluerun_ctx_rehydrate_packet`) that, given a fixed set of durable artifact source paths (task context packet, implementer/reviewer capsules, findings + assumption ledgers, critique records, decision records), emits a single rehydration packet on stdout composed of labeled sections, one per source class.
- Deterministic: identical artifacts yield byte-identical packet and byte-identical manifest across runs, independent of argument or filesystem enumeration order (sources emitted in a fixed, documented order).
- Capped: each section is truncated to at most `GLUERUN_CONTEXT_SECTION_MAX_CHARS` (default 4000, honoring the existing `engine/lib.sh` knob) with a stable truncation marker.
- Quarantine-aware: quarantined artifacts are excluded by composing the integrated `gluerun_ctx_artifact_exclude`, so a `*.quarantined` source, or any source with a `.quarantined` sibling, never reaches the packet or the manifest.
- Manifest: emits, deterministically, the INCLUDED source ids together with their content hashes (the "which artifacts, which hashes" the stage file requires), suitable for a later slice to embed in a strategy event.
- Pure and read-only: it reads artifact paths and hashes their contents but never writes, renames, or deletes anything.

Introducing this file only DEFINES a new function (auto-sourced by the ctx-loader `engine/ctx-*.sh` glob); no existing engine, CLI, or driver path invokes it, so the engine stays byte-identical to current behavior. `GLUERUN_REHYDRATE` (default 0) gates the future routing wire-in, not this pure assembler.

## Acceptance Criteria

- `tests/test-ctx-rehydrate.sh` is written first and fails (red) before `engine/ctx-rehydrate.sh` exists, then passes (green) after implementation; `bash tests/test-engine-clean.sh` stays green (no project-specific symbols in `engine/`).
- Determinism: assembling the packet twice over the same fixed fixture artifacts yields byte-identical packet output and byte-identical manifest; source sections appear in a fixed, documented order regardless of argument or on-disk enumeration order.
- Caps: given a fixture section whose content exceeds `GLUERUN_CONTEXT_SECTION_MAX_CHARS`, that section in the packet is truncated to at most the cap with a stable marker; a lowered `GLUERUN_CONTEXT_SECTION_MAX_CHARS` (e.g. 200) tightens the cap and the default (4000) is honored when the knob is unset.
- Quarantine exclusion: a quarantined artifact (a `*.quarantined` path, or an original whose `.quarantined` sibling exists) never contributes content to the packet and never appears in the manifest; the surviving artifacts still assemble deterministically.
- Manifest: the emitted manifest lists exactly the included source ids, each with a content hash derived from that artifact's bytes; two runs over identical bytes produce identical hashes, and changing one artifact's bytes changes only that entry.
- Purity: the artifact source files are byte-identical before and after assembly (no writes/renames/deletes); the function never exits non-zero on well-formed input.
- Evidence invariance / taint: this assembler is read-only and confers no independence — it neither marks a session as satisfying an independence-required step nor records any source as `authoritative` evidence (rehydrated sessions remain tainted, pinned in `engine/ctx-route.sh`). Authored-knowledge manifest ingestion (`GLUERUN_CTX_MANIFEST`) is a later optional slice and is out of scope.
- Gate candidate: with this slice integrated, `tests/test-ctx-rehydrate.sh` is green and covers determinism, caps, and quarantine exclusion for packet assembly — the assembly portion of the `rehydrate-path` exit gate (routing injection + manifest-in-event coverage lands in later slices).

## Context packet

Decisions:

- Ship the packet assembler as the first `rehydrate-path` brick, mirroring how `engine/ctx-route.sh` deferred its orchestrator until its leaves integrated — the assembler is the leaf the routing wire-in and l1-drive injection hook will later compose. Basis: `docs/context-build-plan/stage-5-routing.md` orders packet assembly before routing integration.
- Emit the manifest (included ids + content hashes) from the assembler itself, not from the routing slice: the manifest is a deterministic byproduct of assembly, so producing it here lets the later routing slice merely embed it into the strategy event. Basis: requiredCompletion couples "capped rehydration packets" with "manifest recorded in strategy events".
- Compose the integrated `gluerun_ctx_artifact_exclude` rather than re-implement quarantine filtering. Basis: TASK-0042 shipped that pure filter for exactly this reuse (its header names "rehydration packet").

Assumptions:

- [validated] `GLUERUN_CONTEXT_SECTION_MAX_CHARS` already exists (default 4000, `engine/lib.sh`) and is the per-section cap to honor — do not introduce a new cap knob.
- [validated] `gluerun_ctx_artifact_exclude` is present and pure (`engine/ctx-artifact-exclude.sh`), accepting paths as args or one-per-line on stdin — compose it for quarantine exclusion.
- [open] Durable artifact source classes are those the stage file lists (task context packet, implementer/reviewer capsules, findings + assumption ledgers, critique records, decision records); this slice may cover a representative subset via fixtures so long as ordering and caps are deterministic — exhaustive source coverage can extend later without breaking this test.
- [validated] Rehydrated sessions are tainted and independence-pinned in `engine/ctx-route.sh`; this assembler must not weaken that (read-only, confers no independence).

Rejected alternatives:

- Wiring the `rehydrate` strategy into `engine/ctx-route.sh` in this slice — rejected: that owns an existing driver-adjacent file and couples routing to assembly; the stage file sequences it after the assembler exists (separate slice, `bash tests/run.sh` gate).
- Recording the manifest directly into strategy events here — rejected: event emission is the routing slice's job; this slice only produces the manifest bytes.
- A present-but-uncalled grep assertion to prove OFF-parity — rejected per planner-contract rule 9 (no temporal negative assertions); OFF-parity holds structurally because a new `ctx-*.sh` only defines a function.
