## Objective

Second strict-test-first slice of the executable DAG node `rehydrate-path` (stage `S5-routing`, layer `engine_runtime`). TASK-0051 shipped the pure packet assembler `engine/ctx-rehydrate.sh` (`singular_ctx_rehydrate_packet` / `singular_ctx_rehydrate_manifest`). This slice adds the pure routing decision that, on a refused-resume lineage-continuation step, decides whether to route the `rehydrate` strategy (fresh session + injected durable context) instead of a bare `fresh`, behind `SINGULAR_REHYDRATE` (default 0).

Introduce a new pure, read-only leaf `engine/ctx-route-rehydrate.sh` in the `ctx-route-*` family (alongside the integrated `ctx-route-window.sh` / `ctx-route-lease.sh` / `ctx-route-diff.sh` / `ctx-route-taint.sh`). It DEFINES a new function only and is present-but-uncalled by every existing engine/CLI/driver path, so with it sourced the engine stays byte-identical to current behavior. The `engine/ctx-route.sh` spine wire-in (calling this leaf on a resume-gate refusal and stamping the packet manifest into the strategy event) and the `l1-drive.sh` packet-injection hook are SEPARATE later slices and are OUT OF SCOPE here.

The seam this leaf models: in `engine/ctx-route.sh` a would-be `resume` that is refused by a resume gate is emitted as `fresh session-lease`, `fresh window-pressure`, or `fresh diff-volume`; the independence pin runs FIRST and has already forced `final-audit`/`paired-audit` to `fresh tainted`, so those never reach the resume gates. The stage file's requiredCompletion is to route `rehydrate` instead of bare `fresh` on exactly those refused-resume lineage-continuation steps when `SINGULAR_REHYDRATE=1`.

Behavior of `engine/ctx-route-rehydrate.sh` (node `rehydrate-path`, layer `engine_runtime`) — a function such as `singular_ctx_route_rehydrate_decide <refusal-reason> <role> <step> <manifest-json>`:

- Prints EXACTLY one line, `rehydrate <refusal-reason>` or `fresh <refusal-reason>`, carrying the original refusal reason forward; never exits non-zero on well-formed input. A pure predicate: appends no events, writes/renames/deletes no files.
- OFF-parity: when `SINGULAR_REHYDRATE` is unset or != 1, it ALWAYS prints `fresh <refusal-reason>` — byte-identical to the reason line `engine/ctx-route.sh` emits today.
- Independence guard (evidence invariance): for an independence-pinned step (`final-audit`, `paired-audit`) it NEVER prints `rehydrate`; it falls back to `fresh <refusal-reason>`, reusing the integrated `singular_ctx_route_independence_admit rehydrate <role> <step>` classification (any non-`admit` verdict ⇒ no rehydrate) so the independence set stays single-sourced.
- Empty-packet guard: when the supplied manifest carries zero surviving sources (all quarantined or none available — an empty `sources` array), it prints `fresh <refusal-reason>`, since there is nothing to inject.
- Otherwise (`SINGULAR_REHYDRATE=1`, a non-pinned lineage-continuation step, and a manifest with at least one surviving source) it prints `rehydrate <refusal-reason>`.

`SINGULAR_REHYDRATE` (default 0) gates only this decision's upgrade; the leaf confers no independence — `rehydrate` remains tainted per the integrated `singular_ctx_route_strategy_tainted`.

- Purity / evidence invariance: the function appends no events, writes/renames/deletes no files, and never exits non-zero on well-formed input; it grants no independence (the `rehydrate` strategy stays tainted per `singular_ctx_route_strategy_tainted`).

## Context packet

Decisions:

- Ship the routing decision as a pure leaf before wiring it into `engine/ctx-route.sh`, mirroring routing-module (leaves `ctx-route-window`/`-lease`/`-diff`/`-taint` → spine `ctx-route.sh` at TASK-0047 → `l1-drive.sh` wire-in at TASK-0048). Basis: leaf-before-spine keeps the existing-file wire-in (full-suite gate) minimal and lets the decision be strategy-table tested in isolation.
- The upgrade applies only to the resume-gate refusals (`fresh session-lease|window-pressure|diff-volume`, `engine/ctx-route.sh` lines ~113–121), which are by construction non-independence-pinned; the independence pin (lines ~83–98) already forces `final-audit`/`paired-audit` to `fresh tainted` before the resume gates run. Basis: stage-5-routing.md scopes the rehydrate route to refused-resume lineage-continuation steps.
- Reuse `singular_ctx_route_independence_admit` for the guard rather than re-listing the pinned steps, so the independence set stays single-sourced (defense in depth even though the spine already pins first). Basis: planner-contract rule 8 (evidence invariance).

Assumptions:

- [validated] `SINGULAR_REHYDRATE` (S5, default 0) is the knob (`docs/context-build-plan/00-overview.md`); OFF must be byte-identical to today's `fresh <reason>` line.
- [validated] `singular_ctx_rehydrate_manifest` emits `{"schema":…,"sources":[{"id","sha256"}…]}` (`engine/ctx-rehydrate.sh`); a zero-length `sources` array means an empty packet ⇒ no upgrade.
- [validated] `singular_ctx_route_independence_admit rehydrate <role> <step>` returns a non-`admit` verdict for `final-audit`/`paired-audit` (`engine/ctx-route-taint.sh`); the leaf treats any non-`admit` as "no rehydrate".
- [open] The leaf takes the already-assembled manifest JSON (not a live artifact set) as input so it stays pure and table-testable; the later spine assembles the manifest via `singular_ctx_rehydrate_manifest` and passes it in. The leaf may inspect only the `sources` length.

Rejected alternatives:

- Wiring the decision straight into `engine/ctx-route.sh` in this slice — rejected: owns an existing file (full-suite gate) and couples the pure decision to strategy-event recording; the spine wire-in plus manifest-into-event is a separate later slice.
- Having the leaf assemble the packet/manifest from artifact paths itself — rejected: duplicates TASK-0051 and makes the decision impure/filesystem-bound; pass the assembled manifest in.
- Emitting `rehydrate` without carrying the refusal reason — rejected: the strategy event must retain WHY resume was refused, so the reason rides through as the `rehydrate` argument.
