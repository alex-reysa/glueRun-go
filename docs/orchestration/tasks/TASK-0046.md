## Objective

Advance the `routing-module` executable DAG node (layer `engine_runtime`) by shipping the two remaining leaf predicates its `requiredCompletion` names beyond the already-integrated window-pressure and diff-volume gates (TASK-0045): the **generalized session lease** read-helpers and the **taint / independence pin**. Building these leaves before the `engine/ctx-route.sh` strategy-dispatcher spine mirrors the sequencing this node already used for its gates and the plan-revision loop (leaves first, composed orchestrator last), so the spine can compose wrapped decide functions + window/diff gates + this generic lease + this taint pin in one later slice without re-touching any leaf.

Both are pure functions in new auto-sourced `engine/ctx-*.sh` files. No existing engine path invokes them, so the engine stays byte-identical (OFF-parity by construction, as in `engine/ctx-route-window.sh`); the `engine/ctx-route.sh` spine, the `GLUERUN_CTX_ROUTING` wire-in, and the second-wave `l1-drive.sh` hook are later slices of this node and are OUT OF SCOPE here.

Slice 1 — generalized session lease (`engine/ctx-route-lease.sh`): generalize the Stage-1 planner-only lease discipline (`gluerun_planner_resume_lease_path` / `_live`, hard-coded to `sessions/planner/<node>.lease`) to every persisted session of any role. `gluerun_ctx_route_session_lease_path <role> <key>` returns the canonical role-generic lease path `<state-dir>/sessions/<role>/<key>.lease` (state-dir `${GLUERUN_STATE_DIR:-$GLUERUN_ROOT/.gluerun-state}`); empty role or empty key returns empty (caller decides). `gluerun_ctx_route_session_lease_live <lease-path>` reproduces the integrated fail-closed liveness table so a router of any role can refuse resume while another fanout holds the session. This is the read side only — the lease-write/acquire/release lifecycle is a driver concern wired in a later slice, exactly as the planner lease lifecycle was.

Slice 2 — taint / independence pin (`engine/ctx-route-taint.sh`): the structural guarantee that resumed/rehydrated sessions can never satisfy an independence-required step. `gluerun_ctx_route_strategy_tainted <strategy>` classifies `resume`/`rehydrate` as tainted (the `tainted=1` the spine will stamp into the strategy event) and `continue`/`fork`/`fresh` as untainted. `gluerun_ctx_route_independence_admit <strategy> <role> <step>` pins the independence-required steps (final audit, paired audit) to `fresh` and refuses any tainted strategy there — no knob may reroute them, honoring the advocate/skeptic line and evidence invariance (planner-contract rule 8).

Both taint functions are pure predicates: they print exactly one line, append no events, write no files, and never exit non-zero.

## Acceptance Criteria

- `engine/ctx-route-lease.sh` defines `gluerun_ctx_route_session_lease_path` and `gluerun_ctx_route_session_lease_live`. `gluerun_ctx_route_session_lease_path <role> <key>` prints `<state-dir>/sessions/<role>/<key>.lease` (state-dir `${GLUERUN_STATE_DIR:-$GLUERUN_ROOT/.gluerun-state}`); empty role OR empty key prints the empty string.
- `gluerun_ctx_route_session_lease_live <lease-path>` is fail-closed: no file → not-live (free); a live PID → live (held); a dead PID → not-live (free; a crashed holder is not concurrency); a lease file with no parseable PID → live (held; cannot prove free → fail closed). It reports liveness by return status without exiting the shell non-zero abnormally, and reproduces the integrated planner lease helper's verdicts for the `planner` role/key.
- `engine/ctx-route-taint.sh` defines `gluerun_ctx_route_strategy_tainted` and `gluerun_ctx_route_independence_admit` as pure predicates (append no events, write no files, print exactly one line, never exit non-zero).
- `gluerun_ctx_route_strategy_tainted <strategy>` prints `1` for `resume` and `rehydrate`, `0` for `continue`, `fork`, and `fresh`, and `1` for any unknown or empty strategy (fail closed — an unrecognized strategy is treated as tainted so it cannot slip past the independence pin).
- `gluerun_ctx_route_independence_admit <strategy> <role> <step>`: for an independence-required step (the fixed documented set `final-audit`, `paired-audit`) it prints `admit` only when the strategy is `fresh`, `refuse tainted` when the strategy is `resume`/`rehydrate`, and `refuse pinned-fresh` for any other non-`fresh` strategy; for any non-independence-required step it prints `admit`.
- No `GLUERUN_*` environment knob relaxes an independence-required step: with routing knobs set to any values, `resume` and `rehydrate` at `final-audit` and `paired-audit` still print `refuse tainted` (the pin is structural — tested by setting knobs and re-asserting), and the taint gate only ADDS refusals for independence-required steps, never converting a would-be-refused decision into an `admit`.
- `bash tests/test-ctx-route-lease.sh` and `bash tests/test-ctx-route-taint.sh` are red before implementation and green after; `bash tests/test-engine-clean.sh` stays green (no project-specific symbols in `engine/`).
- GATE CANDIDATE (node-level, not declared here): composed with the later `engine/ctx-route.sh` dispatcher, `routing-module` (a) refuses concurrent resume via a live generalized session lease and (b) makes the final-audit and paired-audit steps structurally unreachable by resumed/rehydrated sessions — two more of the node's `requiredCompletion` predicates.

## Context packet

Decisions:
- Ship the two remaining routing leaves (generalized session-lease read-helpers; taint classifier + independence pin) before the `engine/ctx-route.sh` spine — the same leaf-before-orchestrator sequencing this node used for its gates (TASK-0045) and the plan-revision loop (TASK-0019..0023), so the spine composes wrapped decide functions + window/diff gates + generic lease + taint pin in one later slice without re-touching any leaf.
- Generic lease = role/key path + fail-closed liveness only (read side), reproducing the integrated planner pair; the lease-write/acquire/release LIFECYCLE is a driver concern wired later (as the planner lease lifecycle was, TASK-0011).
- The taint independence set is fixed and non-weakenable (`final-audit`, `paired-audit`); no knob may reroute it — matches planner-contract rule 8 and stage-5 `no knob may reroute them`.
- Fail-closed direction: unreadable lease PID → held; unknown strategy → tainted; both prefer the safe (fresh/refuse) side, mirroring the integrated gates and `gluerun_planner_resume_decide`.

Rejected alternatives:
- Spine-first (`engine/ctx-route.sh` now with lease/taint inline): rejected — it would re-touch the node's central file when the leaves land and duplicate the planner lease/liveness logic inline; build reusable leaves first.
- Making the independence set overridable by a `GLUERUN_*` knob for testability: rejected — a knob that relaxes an independence-required step is exactly the advocate/skeptic violation the contract forbids; tests drive the fixed set directly.
