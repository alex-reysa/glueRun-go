## Objective

An infra retry currently destroys the previous try's entire worker trace: in
`engine/l1-drive.sh` `run_worker_phase`, every try redirects with a truncating
`>"$run_dir/worker-codex.log"` (main run and the rc-86 resume-fallback rerun). Try 0's bytes
are gone the instant try 1 spawns; only the per-try `*.provider-envelope.raw` sidecar survives,
and stderr-only runner diagnostics (resume-refused, terminal-failure notices) are lost outright.
The auditor already has the correct behavior — `auditor-codex.log` is opened with `>>` and each
try is prefixed by a `--- auditor try N (attempt M) ---` separator — and `audit-verify.sh`
already established the `<name>-${attempt}-${try}` per-try naming convention. This task brings
the worker to parity and completes the attempt-archive copy set.

Required changes:

1. In `run_worker_phase`, write each try's stream to a per-try file
   `worker-attempt-<n>-try-<m>.log` (and the resume-fallback rerun to
   `worker-attempt-<n>-try-<m>-resume-fallback.log`), then append the same bytes plus a
   `--- worker try <m> (attempt <n>) ---` header to `worker-codex.log`, which becomes
   append-only for the life of the run. `worker-codex.log` stays at its current path and name:
   it is the compatibility view read by `evidence-manifest.sh`, the console adapter, and the
   ctx-route window gate, and after this change its byte count reflects cumulative session
   output instead of only the last try (fixing the systematic underestimate in the routing
   window gate).
2. Readers that need exactly one try's output (failure classification via
   `singular_planner_failure_class`) must read the per-try file, not the aggregate.
3. Extend `singular_attempt_archive` in `engine/lib.sh`: add `auditor-codex.log`, the per-try
   `worker-attempt-*-try-*.log` files, and the per-try `*runner-result.json` +
   `*.provider-envelope.raw` sidecars for the archived attempt to the copy set. Copies only;
   root files are never moved or renamed.
4. Repair the dogfood bootstrap defect reproduced by `test-executable-resolution.sh`:
   `singular status` currently enters `reconcile.sh`, creates state directories, and calls
   `singular_ensure_repo_scaffold` before the status early-return. A nominally read-only
   status call therefore touches `.gitignore` and atomically replaces every schema mirror,
   causing the strict integration source-integrity monitor to reject an otherwise green
   194/194 suite. Move the status path ahead of every state/scaffold mutation and pin that it
   remains observational. This is bundled into the first serial slice because leaving it
   until rel-06 would require the bootstrap adapter on every intervening self-hosted merge.
5. Remove the detached-dispatch race reproduced during TASK-0108's exact-tree integration gate.
   `test-reconcile-low-disk.sh` currently observes `dispatch_gate=open` and immediately requires
   the detached driver completion marker even though reconcile deliberately returns without
   waiting. Keep detached mode under test, but wait for the driver marker or terminal dispatch
   record with a bounded deadline, drain every child before fixture cleanup, and fail with the
   durable dispatch evidence on timeout. Ten unchanged isolated runs reproduced three failures;
   all three synchronous controls passed, and failed cleanup retained a late `exit=137` sentinel.
6. Make `test-per-try-artifacts.sh` hermetic to the checkout that invokes it. The first dogfood
   attempt sourced `engine/lib.sh` after installing a no-op `singular_append_event` stub; the
   source replaced that stub while the test still inherited the live driver's
   `SINGULAR_STATE_DIR`/`SINGULAR_EVENTS_FILE`. Eight fixture events with `runId=resume-run`
   escaped into the authoritative sprint event log across worker and host-verification runs.
   Bind every state/event path to the fixture before sourcing production helpers, and prove the
   invoking checkout's event bytes and file set are unchanged. Rebind
   `SINGULAR_JSON_CONFIG_FILE`, `SINGULAR_CONFIG_FILE`, and `SINGULAR_LOCAL_CONFIG_FILE` to
   fixture-local or intentionally absent paths before sourcing `lib.sh`, and set
   `SINGULAR_ROOT`/`SINGULAR_ENGINE_HOME` deliberately, so live config cannot overwrite fixture
   knobs through the precedence defect already observed in this dogfood run.
