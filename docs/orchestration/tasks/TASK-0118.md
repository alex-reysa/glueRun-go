## Objective

The engine has four overlapping failure vocabularies (orchestration `attempt_failure` classes,
`runner-result.v0`'s provider `failureClass` enum, `gate-report.v0`'s outcome +
`infrastructureSignals`, and the health-details categories) and no single field an operator or
metric can group by. The audit's routing findings (evidence remedies drawing product budget,
one-shot infra parks) are invisible in history because nothing records WHICH domain consumed a
remedy. Do NOT introduce a new competing `failure.v0` record — formalize what already exists.

Required changes:

1. One derivation helper in `engine/lib.sh`: `singular_failure_domain CLASS` mapping the
   orchestration class vocabulary to exactly one of `product`, `evidence`, `infrastructure`,
   `worker-runtime`, `integrity`, `unknown` (fail closed to `unknown` for unrecognized
   classes; `unknown` must never be silently treated as retryable). Table (from the audited
   emitter census):
   - product: `gate-red`, `audit-needs-fix`, `no-changes`, `worker-no-packet`,
     `packet-invalid`, `proof-skip-detected`, `commit-failed`, `scope-violation`
   - evidence: the evidence-manifest/bind emitter split introduced by rel-05, plus
     `revalidate-evidence` remedies
   - infrastructure: `worker-infra`, `audit-infra`, `stale-lease`
   - worker-runtime: `timeout`-derived worker classes surfaced by the runner contract
   - integrity: `integrity-violation`, `secret-detected`
2. Stamp `failureDomain` additively wherever the class is already persisted: the attempts
   index entry (`singular_attempt_archive`'s index upsert) and the decider event payloads.
   No consumer behavior may key off it yet — it is observational this release.
3. Formalize the existing attempts-index record: new
   `schemas/attempts-index.v0.schema.json` validating what `singular_attempt_archive` already
   writes (`singular.orchestration.attempts-index.v0` with `n`, timestamps, `failureClass`,
   `auditVerdict`, `headSha`, `deciderAction`, `deciderAuthority`, `dir`, strategies) plus the
   new optional `failureDomain`. All existing fields optional-tolerant so historical index
   files validate.
